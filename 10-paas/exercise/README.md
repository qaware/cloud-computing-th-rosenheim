# Practice session PaaS

In today's practice session you will deploy applications using two different Platform-as-a-Service (PaaS) offerings.

## Parts

[Part 1 - AWS](./01-aws): Deploy a container to AWS with Amazon ECS Express Mode, starting from your own VPC and container registry.  
[Part 2 - Vercel](./02-vercel): Deploy a web frontend straight from a Git repository with Vercel.

Both parts are independent of each other. If you don't have access to an AWS account, start with Part 2.
